# ESP32 Temperature and Humidity Monitor

A temperature and humidity monitoring system built using an ESP32
and DHT11 sensor. Sensor readings are displayed through the Blynk IoT
platform.

## Features

- Real-time temperature monitoring
- Real-time humidity monitoring
- DHT11 sensor interfacing
- ESP32 Wi-Fi connectivity
- Blynk IoT dashboard integration

## Components Used

- ESP32
- DHT11 Temperature & Humidity Sensor
- Breadboard
- Jumper wires
- USB cable

## Software

- Arduino IDE
- Blynk IoT
- ESP32 Arduino Core

## How It Works

The DHT11 sensor measures temperature and humidity.
The ESP32 reads the sensor data and sends the readings
to the Blynk IoT platform over Wi-Fi.
